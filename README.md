# TunnelHop

Desktop orchestrator for WireGuard and OpenVPN on Windows: imports a configuration bundle, rotates between profiles on a schedule, and keeps traffic blocked by its own kill-switch while it switches.

Status: the platform-independent core is done; the Windows service, drivers, kill-switch and UI are next.
